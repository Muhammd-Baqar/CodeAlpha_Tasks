\# Hotel Reservation System



\## Description

A Java console-based Hotel Reservation System developed using Object-Oriented Programming (OOP) and File Handling.



\## Features

\- View Available Rooms

\- Book Room

\- Cancel Booking

\- View Booking Details

\- Payment Management

\- Save Booking Data Using File Handling



\## Technologies Used

\- Java

\- OOP

\- ArrayList

\- File Handling

\# Stock Trading Platform



\## Description

A Java console-based Stock Trading Platform developed using Object-Oriented Programming (OOP) and File Handling.



\## Features

\- Display Market Data

\- Buy Stocks

\- Sell Stocks

\- View Portfolio

\- Calculate Portfolio Value

\- Save Portfolio Using File Handling



\## Technologies Used

\- Java

\- OOP

\- ArrayList

\- File Handling

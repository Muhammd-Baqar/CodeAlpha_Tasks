\# Student Grade Tracker



\## Description

A Java console-based Student Grade Tracker developed using Object-Oriented Programming (OOP) and File Handling.



\## Features

\- Add Student

\- View Students

\- Search Student

\- Update Student

\- Delete Student

\- Calculate Percentage

\- Calculate Grade

\- Store Data Using File Handling



\## Technologies Used

\- Java

\- OOP

\- ArrayList

\- File Handling

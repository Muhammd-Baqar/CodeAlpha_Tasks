# CodeAlpha Java Programming Tasks

This repository contains my Java projects completed during the CodeAlpha Java Programming Internship.

## Projects

### Task 1: Student Grade Tracker
A Java console application to manage student records, calculate percentages and grades, and store data using file handling.

**Features**
- Add Student
- Search Student
- Update Student
- Delete Student
- Grade & Percentage Calculation
- File Handling

### Task 2: Stock Trading Platform
A Java console application that simulates a basic stock trading environment.

**Features**
- Display Market Data
- Buy Stocks
- Sell Stocks
- Portfolio Management
- File Handling

### Task 3: Hotel Reservation System
A Java console application for hotel room booking and reservation management.

**Features**
- View Available Rooms
- Book Room
- Cancel Booking
- View Booking
- File Handling

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Array List
- File Handling
